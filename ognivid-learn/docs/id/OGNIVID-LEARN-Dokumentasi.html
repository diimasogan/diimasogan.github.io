Ringkasan eksekutif

OGNIVID LEARN adalah platform belajar online yang saya pasang, konfigurasi, dan jalankan di WordPress self-hosted: kursus dengan kuis dan tugas, toko dalam Rupiah dengan checkout, sertifikat yang bisa diverifikasi, bootcamp live, dan program instruktur, semuanya dalam Bahasa Indonesia.

Ini situs publik yang benar-benar berjalan, bukan demo, dan menunjukkan pekerjaan WordPress self-hosted secara utuh: instalasi dan konfigurasi, setup LMS dan e-commerce, plugin custom, e-mail transaksional, desain, serta operasional harian.

Yang saya bangun

WordPress self-hosted

Instalasi WordPress terpisah dari ognivid.com, berbahasa Indonesia dan zona waktu UTC+7, dengan HTTPS, cache halaman di server, dan CDN.

Learning management

Tutor LMS Pro dengan kursus, bab, kuis, tugas proyek, dan aturan penyelesaian yang ketat.

Toko & checkout

WooCommerce dalam Rupiah: keranjang, checkout ringkas yang otomatis membuat akun, transfer bank dengan konfirmasi WhatsApp, dan pendaftaran kursus otomatis saat pesanan selesai.

Sertifikat terverifikasi

Tiga template bermerek (Completion, Participation, Appreciation). Setiap sertifikat punya nomor unik yang bisa diverifikasi siapa pun di situs.

Event & bootcamp

Bootcamp online live dengan landing page sendiri, harga Early Bird berbasis waktu, produk add-on, pengumpulan proyek, dan penilaian manual.

Program instruktur

Pendaftaran instruktur lewat undangan, persetujuan admin, review kursus sebelum terbit, dan penarikan dana via transfer bank.

Desain & pengalaman pengguna

Satu sistem visual

Tema gelap dengan aksen hijau limau dan font Figtree di semua halaman Elementor, WooCommerce, dan dashboard Tutor. Halaman Tutor lama yang masih terang diberi stylesheet gelap hasil generate.

Landing page panduan

Panduan langkah demi langkah dengan screenshot asli: cara checkout (6 langkah) dan cara akses kelas (7 langkah), masing-masing dengan FAQ.

Landing bootcamp

Jadwal, materi, rundown, paket harga, brief proyek, contoh sertifikat, pembicara, dan FAQ dalam satu halaman.

Desain sertifikat

Sertifikat dirender dari HTML dan diposisikan presisi, termasuk solusi untuk pergeseran 5px di certificate builder Tutor.

Aset promosi

Thumbnail kursus dan poster dibuat dengan HTML, dirender dengan Chrome headless, lalu diekspor sebagai PNG dan file Canva yang bisa diedit.

Alur belajar jelas

Penyelesaian ketat: semua pelajaran selesai dan semua kuis atau tugas lulus, baru sertifikat terbit otomatis.

Dibangun dan dikelola sebagai kode

Sebagian besar situs dibuat dari repositori Git private, sehingga setiap perubahan bisa diulang dan ditinjau.

1

Generate

Generator Python membuat data Elementor untuk beranda dan setiap landing page, plus CSS global.

2

Backup

Sebelum ada perubahan, pengaturan dan data halaman yang sedang aktif diekspor ke JSON.

3

Kirim

Perubahan dikirim lewat WordPress REST API dengan sesi login sementara; pelajaran dan kuis kursus dikirim dengan cara yang sama.

4

Verifikasi

Cache Elementor dan hosting dibersihkan, lalu halaman live dibandingkan dengan payload yang dibuat.

Keamanan & operasional

Tidak ada rahasia di repo

Password disimpan di file lokal dengan izin terbatas; cookie login dan nonce REST dihapus setelah setiap sesi.

E-mail andal

Semua e-mail lewat SMTP terautentikasi dengan SSL, bukan PHP mail, sehingga e-mail pesanan dan sertifikat sampai ke inbox.

Update aman

Kustomisasi ada di plugin dan generator, bukan di file core atau plugin yang diubah, dan dicek ulang setiap kali Tutor di-update.

Alur pesanan

Pesanan ditahan sampai pembayaran dikonfirmasi; saat ditandai selesai, siswa otomatis terdaftar dan menerima e-mail.

Pemisahan peran

Alur dan dashboard terpisah untuk siswa, instruktur, dan admin, dengan persetujuan admin untuk instruktur dan kursusnya.

Terdokumentasi

Buku panduan internal mencakup setiap komponen, operasional harian, dan cara menjalankan ulang setiap script.

Yang ditunjukkan project ini

  • Memasang dan mengonfigurasi WordPress self-hosted untuk bisnis nyata, termasuk bahasa, zona waktu, HTTPS, cache, dan CDN.
  • Mengintegrasikan LMS, toko e-commerce, dan e-mail transaksional menjadi satu alur yang berjalan, dari checkout sampai sertifikat.
  • Menulis plugin WordPress custom dengan PHP untuk perbaikan bug, aturan bisnis, dan terjemahan.
  • Mengelola WordPress dan Elementor lewat REST API dengan script, backup, dan deployment yang bisa diulang.
  • Merancang pengalaman pengguna berbahasa Indonesia yang konsisten di tema, LMS, dan toko.
