Executive summary

OGNIVID LEARN is an online learning platform I installed, configured and run on self-hosted WordPress: courses with quizzes and assignments, a Rupiah store with checkout, verifiable certificates, live bootcamps and an instructor programme, all in Indonesian.

It is a working, public site, not a demo, and it shows the full self-hosted WordPress job: installation and configuration, LMS and e-commerce setup, custom plugins, transactional e-mail, design, and day-to-day operation.

What I set up

Self-hosted WordPress

A separate WordPress install from ognivid.com, set to Indonesian and UTC+7, with HTTPS, server-side page cache and CDN.

Learning management

Tutor LMS Pro with courses, chapters, quizzes, project assignments and strict completion rules.

Store & checkout

WooCommerce in Rupiah: cart, short checkout that creates the account automatically, bank transfer with WhatsApp confirmation, and automatic enrolment when an order is completed.

Verifiable certificates

Three branded templates (Completion, Participation, Appreciation). Each certificate has a unique number that anyone can verify on the site.

Events & bootcamps

Live online bootcamps with their own landing page, time-based Early Bird pricing, add-on products, project submission and manual grading.

Instructor programme

Invite-only instructor registration, admin approval, course review before publishing, and withdrawals by bank transfer.

2 · Indonesian translation for Tutor LMS (v1.0.6)

Tutor LMS has no official Indonesian translation. This plugin translates about 1,440 strings from Tutor and Tutor Pro, in both PHP and JavaScript, and is built from a JSON source with a small build script.

Design & user experience

One visual system

Dark theme with a lime accent and the Figtree font across Elementor pages, WooCommerce and the Tutor dashboard. Tutor's older light pages get a generated dark stylesheet.

Guided landing pages

Step-by-step guides with real screenshots: how to check out (6 steps) and how to access a class (7 steps), each with an FAQ.

Bootcamp landing

Schedule, syllabus, rundown, pricing tiers, project brief, sample certificate, speaker and FAQ on one page.

Certificate design

Certificates rendered from HTML and positioned precisely, including a workaround for a 5px offset in Tutor's certificate builder.

Marketing assets

Course thumbnails and posters built in HTML, rendered with headless Chrome and exported as PNG and editable Canva files.

Clear learning flow

Strict completion: every lesson finished and every quiz or assignment passed before the certificate is issued automatically.

Built and maintained as code

Most of the site is generated from a private Git repository, so every change is repeatable and reviewable.

1

Generate

Python generators build the Elementor data for the home page and each landing page, plus the global CSS.

2

Back up

Before any change, the current settings and page data are exported to JSON.

3

Push

Changes are sent through the WordPress REST API with a short-lived login session; course lessons and quizzes are pushed the same way.

4

Verify

Elementor and hosting caches are cleared and the live page is compared with the generated payload.

Security & operations

No secrets in the repo

Passwords stay in a local file with restricted permissions; login cookies and REST nonces are deleted after each session.

Reliable e-mail

All mail goes through authenticated SMTP over SSL instead of PHP mail, so order and certificate e-mails reach the inbox.

Safe updates

Customisations live in plugins and generators, not in edited core or plugin files, and must be re-checked after Tutor updates.

Order workflow

Orders stay on hold until payment is confirmed; marking them completed enrols the student and sends the e-mail automatically.

Role separation

Separate flows and dashboards for students, instructors and admin, with admin approval for instructors and their courses.

Documented

An internal handbook covers every component, daily operations and how to re-run each script.
